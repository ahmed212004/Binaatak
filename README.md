# بناءتك | Binaatak Marketplace

واجهة تجريبية عربية RTL لسوق المقاولات والهندسة والتوريدات، مبنية باستخدام React 18 وTypeScript وVite وTailwind CSS وReact Router v6 وLucide React.

## التشغيل

```bash
npm install
npm run dev
```

ثم افتح الرابط الذي يعرضه Vite (غالباً `http://localhost:5173`).

لإنشاء نسخة إنتاجية:

```bash
npm run build
npm run preview
```

## أهم المجلدات

- `src/data/mockData.ts`: بيانات العرض التجريبية، أنواع الحسابات، وشجرة التصنيفات ذات المستويات الثلاثة.
- `src/components/`: شريط التنقل، المكونات المشتركة، منتقي التصنيف، والنوافذ المنبثقة.
- `src/pages/AppPages.tsx`: صفحات ومسارات التطبيق الرئيسية.
- `src/styles.css`: تنسيقات Tailwind والأنماط المخصصة والتجاوب.

## المسارات

`/`، `/directory`، `/rfqs`، `/rfqs/:id`، `/jobs`، `/messages`، `/profile`، `/login`، `/register`.

## ملاحظات مهمة

- التطبيق يعمل ببيانات Mock محلية في حالة React؛ الإضافات والرسائل والعروض تتحدث في الواجهة أثناء الجلسة فقط.
- تسجيل الدخول وإنشاء الحساب واجهات توضيحية وليسا موصولين بخادم أو قاعدة بيانات.
- لا توجد حالياً خدمة رفع ملفات فعلية أو إرسال مرفقات؛ زر المرفقات في المحادثة عنصر واجهة فقط.
- عروض الأسعار المقارنة تحتوي على سجل تجريبي لتوضيح شاشة صاحب الطلب.
- ربط Backend ورفع الملفات والمصادقة الدائمة يتطلب API وقاعدة بيانات وصلاحيات مستخدمين.
